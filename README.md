# 모사 (Mosa) — 바닷속 모사사우루스 🦕🐋

**3~4살 아이를 위한 한 버튼 수 세기 게임.** 크롬 공룡 게임의 "버튼 하나, 동작 하나" 구조를 바닷속으로 옮겼습니다.
고래가 한 마리씩 지나가고, 버튼을 누르면 모사사우루스가 달려가 냠! 하고 돌아옵니다. 잡을 때마다 숫자가 올라가고 "하나, 둘, 셋…" 한글로 세어 줍니다.

> 🎮 플레이: _(배포 후 링크)_ · 📦 `index.html` 하나로 돌아갑니다 — 설치·빌드·서버 없음

---

## 왜 만들었나

아이가 게임을 좋아하는데, 보통 게임은 **더 오래 붙잡아 두도록** 설계되어 있습니다. 모사는 반대로 설계했습니다.

- **짧게 놀고 스스로 끝나는 게임** — 5분이 지나면 바다가 어두워지고 모사가 잠듭니다. 30분 뒤에야 다시 놀 수 있습니다.
- **실패도, 경쟁도 없음** — 놓친 고래는 그냥 지나갑니다. 점수판·랭킹·최고 기록 없음.
- **놀면서 수를 배움** — 매번 숫자와 한글 수사를 함께 보고 듣습니다.
- **광고·수집·알림 없음** — 파일 하나, 오프라인에서도 동작, 밖으로 나가는 데이터 없음.

## 아이가 배우는 것

| 영역 | 어떻게 |
|---|---|
| **수 세기** | 잡을 때마다 "3" + "셋" 말풍선이 뜨고 소리로 읽어 줌. 하나·둘·셋 … 열하나 … 스물 … 아흔아홉까지 |
| **숫자 ↔ 말 연결** | 아라비아 숫자(3)와 한글 수사(셋)를 항상 나란히 표시 |
| **단위 세기** | 끝 화면에서 "오늘은 고래를 **세 마리** 먹었어요" — 한/두/세/네 마리 변형을 자연스럽게 노출 |
| **인과관계** | 버튼 → 모사가 움직임. 고래가 없을 때 눌러도 꿈틀 + 거품으로 "들었어" 반응 |
| **기다리기** | 고래는 1~3초 간격으로 한 마리씩. 연타해도 한 번만 동작 |
| **바다 생물** | 대왕고래·혹등고래·범고래·벨루가·일각고래·향유고래, 생김새가 다 다름 |
| **끝맺음** | 밤이 오고 모사가 자는 걸 보며 "놀이에는 끝이 있다"를 자연스럽게 경험 |

## 놀이 방법

1. `index.html` 열기 (또는 배포된 링크)
2. **스페이스바 / 아무 키 / 화면 터치** — 시작도, 잡기도 이것 하나
3. 고래가 보이면 누르기 → 냠! → 숫자와 소리
4. 5분 뒤 바다가 잠들면 끝. 오늘 먹은 고래를 같이 세어 보세요

오른쪽 위: 전체화면 ⛶, 소리 🔊 (키보드 `M`)

## 부모를 위한 설정

`index.html` 상단 `CONFIG`:

| 항목 | 기본값 | 설명 |
|---|---|---|
| `SESSION_SECONDS` | 300 (5분) | 한 번에 놀 수 있는 시간 |
| `COOLDOWN_SECONDS` | 1800 (30분) | 끝난 뒤 다시 놀 수 있을 때까지 |
| `WHALE_GAP` | 1.0~2.6초 | 고래 등장 간격 |
| `WHALE_SPEED` | 28~60 px/s | 고래 속도 |

쿨다운은 브라우저 `localStorage`에 저장되어 새로고침해도 유지됩니다.
마지막 25% 구간에는 바다가 서서히 어두워져 아이가 "곧 끝나겠구나"를 미리 느낍니다.

테스트용 URL 파라미터: `?session=20&cooldown=10` (초 단위), `?reset` (쿨다운 기록 삭제)

## 목소리

게임은 `voice/` 폴더에 클립이 있으면 그걸 틀고, 없으면 브라우저 내장 TTS(Web Speech API)로 대체합니다.

```
voice/n/1.mp3 … n/70.mp3         "하나!" "둘!" …
voice/count/1.mp3 … count/70.mp3  "오늘은 고래를 한 마리 먹었어요. 잘 자요."
voice/sleep.mp3                   "바다가 잠들었어요. 잘 자요."
```
확장자는 mp3 / m4a / webm / wav 자동 감지. 일부만 있어도 되고(없는 건 TTS), 폴더가 없어도 됩니다.

**① 어린이 AI 목소리 — 네이버 CLOVA Voice (추천)**
CLOVA Voice Premium에 아동 음성이 있습니다: `nhajun`(하준·남아) `ndain`(다인·여아) `ngaram`(가람·여아) `nmeow`(야옹이) `nwoof`(멍멍이).
네이버 클라우드 플랫폼에서 CLOVA Voice 앱 등록 → 키 발급 후:
```
NCP_CLIENT_ID=... NCP_CLIENT_SECRET=... node tools/gen-voice.mjs nhajun
```
전체 2천 자 정도라 비용은 거의 없습니다.

**② 엄마·아빠·아이 목소리 직접 녹음**
`tools/record.html`을 열고 문구마다 녹음(스페이스바 녹음/정지, ←→ 이동) → ZIP 다운로드 → `voice/`를 `index.html` 옆에 두면 끝. 숫자 1~30 + 인사만 해도 충분합니다. 3~4살에게는 아는 목소리가 제일 잘 통합니다.

**③ 내장 TTS 품질 올리기**
macOS: 시스템 설정 → 손쉬운 사용 → 말하기 콘텐츠 → 음성 관리 → 한국어 **유나(프리미엄)** 다운로드.

## 기술

- HTML + Canvas + 바닐라 JS **단일 파일**, 의존성 0, 빌드 0
- 모사사우루스·고래 6종 모두 코드로 그림 (외부 이미지 없음 → 라이선스 걱정 없음)
- 효과음은 Web Audio로 합성 (냠·휙·반짝·잠들기 멜로디·물소리)
- 패럴랙스 배경 5층 (해초/조개 → 가까운 바위 → 먼 바위 → 물고기 → 빛줄기)
- 상태 머신 `idle → dash → chomp → return`, 입력은 `idle`에서만
- 탭이 숨겨지면 타이머 정지, 더블탭 확대·스크롤·우클릭 차단
- 글꼴: Google Fonts **Jua** (없으면 시스템 글꼴)

```
index.html         게임 전체
tools/gen-voice.mjs  CLOVA 어린이 음성 클립 생성
tools/record.html    직접 녹음 페이지
voice/             (선택) 음성 클립
```

## 앞으로의 계획

### 다음에 할 것 (교육 효과 대비 작업량이 좋은 순)

1. **어린이 목소리 적용** — CLOVA `nhajun`/`ndain` 클립 생성해서 배포에 포함. 지금 TTS는 로봇 같음
2. **고래 이름 읽어주기** — 잡을 때 "범고래!" 한 번 더. 수 세기 + 어휘를 한 번에
3. **열 단위 축하** — 10, 20마리째에 특별한 반짝임 + "열!" 강조. '열 묶음' 개념의 씨앗
4. **끝 화면 숫자판** — 오늘 잡은 만큼 1·2·3… 카드가 고래 아이콘과 짝지어 나열. 일대일 대응을 눈으로
5. **부모 설정 화면** — 화면 구석 3초 길게 누르기(아이는 못 함) → 세션/쿨다운/소리/속도. 코드 안 열어도 되게
6. **PWA** — 홈 화면에 추가, 완전 오프라인, 태블릿 전체화면. 아이에게 "앱"처럼 건네주기

### 나중에

- **영어 모드** — one, two, three 토글. 같은 게임으로 이중언어
- **세로 화면 대응** — 지금은 가로 기준. 태블릿 세로로 들었을 때도 레이아웃 유지
- **난이도 자연 조절** — 세션 중반부터 고래가 조금 빨라짐 (실패는 여전히 없음)
- **하루 총량 제한** — 세션 수를 하루 2~3회로. 지금은 30분 쿨다운만
- **색·크기 말하기** — "파란 고래", "큰 고래" 같은 수식어 노출 (수 세기 다음 단계)
- **'냠' 대신 '하이파이브' 옵션** — 잡아먹는 설정이 불편한 가정을 위한 토글

### 일부러 안 할 것

이건 기능이 아니라 원칙입니다. 아이용 게임에서 흔하지만 **넣지 않습니다.**

- 점수 경쟁, 최고 기록, 랭킹, 별점
- 보상 루프 (뽑기, 수집, 열쇠, 일일 보상)
- "한 판 더" 유도, 쿨다운 건너뛰기 버튼
- 푸시 알림, "오랜만이에요" 류 재방문 유도
- 광고, 인앱 결제, 외부 데이터 전송
- 무한 플레이 모드
