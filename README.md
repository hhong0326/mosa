# 모사 (Mosa) — 바닷속 모사사우루스

3~4살 아이를 위한 한 버튼 웹게임. 크롬 공룡 게임 구조를 바닷속으로 옮겼습니다.

- 모사사우루스가 왼쪽에서 제자리 헤엄
- 고래가 한 마리씩 오른쪽에서 등장 (대왕고래·혹등고래·범고래·벨루가·일각고래·향유고래)
- **스페이스바 / 아무 키 / 화면 터치** → 고래에게 돌진 → 냠! → 원위치
- 실패 없음. 잡을 때마다 숫자가 올라가고 **한글로 세 줌** — 화면에 "3 셋" 말풍선 + 음성 "셋!"
- 끝나면 "오늘은 고래를 세 마리 먹었어요"처럼 단위 붙여 읽어 줌
- 배경(해초·바위·물고기·빛줄기)이 패럴랙스로 흘러가 앞으로 헤엄치는 느낌
- **5분**이 지나면 바다가 어두워지며 "바다가 잠들었어요" 화면 → **30분** 쿨다운

## 실행

`index.html`을 브라우저에서 열면 끝입니다. 빌드·서버·외부 에셋 없음 (글꼴 Jua만 Google Fonts에서 불러오고, 없으면 시스템 글꼴 사용).

## 부모용 설정

`index.html` 상단 `CONFIG`:

| 항목 | 기본값 | 설명 |
|---|---|---|
| `SESSION_SECONDS` | 300 | 한 번에 놀 수 있는 시간 |
| `COOLDOWN_SECONDS` | 1800 | 끝난 뒤 다시 놀 수 있을 때까지 |
| `WHALE_GAP` | 1.0~2.6초 | 고래 등장 간격 |
| `WHALE_SPEED` | 28~60 px/s | 고래 속도 |

쿨다운은 브라우저 `localStorage`에 저장되므로 새로고침해도 유지됩니다.

### 테스트용 URL 파라미터

```
index.html?session=20&cooldown=10   # 20초 세션, 10초 쿨다운
index.html?reset                    # 쿨다운 기록 삭제
```

### 조작

- 화면 오른쪽 위: 전체화면 / 소리 끄기 (키보드 `M`도 음소거 토글)
- 소리는 Web Audio로 합성 (파일 없음). 첫 입력 후부터 재생됩니다.
- 수 세기: 하나·둘·셋 … 열하나 … 스물 … 아흔아홉 (`koNumber`), 단위 붙일 땐 한·두·세·네·스무 마리 (`koCount`).

## 목소리

게임은 `voice/` 폴더에 클립이 있으면 그걸 틀고, 없으면 브라우저 내장 TTS(Web Speech API)로 대체합니다.

```
voice/n/1.mp3 … n/70.mp3        "하나!" "둘!" …
voice/count/1.mp3 … count/70.mp3 "오늘은 고래를 한 마리 먹었어요. 잘 자요."
voice/sleep.mp3                  "바다가 잠들었어요. 잘 자요."
```
확장자는 mp3 / m4a / webm / wav 중 자동 감지. 일부만 있어도 되고(없는 건 TTS로), 폴더 전체가 없어도 됩니다.

**방법 1 — 어린이 AI 목소리 (네이버 CLOVA Voice)**
CLOVA Voice Premium에 진짜 아동 음성이 있습니다: `nhajun`(하준·남아), `ndain`(다인·여아), `ngaram`(가람·여아), `nmeow`(야옹이), `nwoof`(멍멍이).
네이버 클라우드 플랫폼에서 CLOVA Voice 앱을 등록해 키를 받은 뒤:
```
NCP_CLIENT_ID=... NCP_CLIENT_SECRET=... node tools/gen-voice.mjs nhajun
```
전체 텍스트가 2,000자 정도라 글자 수 과금 기준으로 비용은 거의 없습니다.

**방법 2 — 엄마·아빠·아이 목소리 직접 녹음**
`tools/record.html`을 브라우저로 열고 문구마다 녹음(스페이스바로 녹음/정지, ←→ 이동) → ZIP 다운로드 → 압축 풀어 `voice/`를 `index.html` 옆에 두면 끝. 숫자 1~30 + 끝 인사만 녹음해도 충분합니다.

**TTS 품질 올리기 (클립 없을 때)**
macOS: 시스템 설정 → 손쉬운 사용 → 말하기 콘텐츠 → 시스템 음성 → 음성 관리 → 한국어 **유나(프리미엄)** 다운로드. 기본 압축판보다 훨씬 자연스럽습니다. 크롬은 온라인 "Google 한국의" 음성을 우선 씁니다.
